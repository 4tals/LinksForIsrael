# **Links For Israel - לינק לישראל**

🌐 **<https://www.linksforisrael.com/>** · 🇺🇸 **<https://www.linksforisrael.com/en>**

## 📖 **Introduction**

Welcome to **Links For Israel** — an open-source, ad-free civic directory connecting people with verified Israeli nonprofits, volunteering networks, mental health and veteran support, citizen rights resources, and emergency hotlines — year-round, in routine and emergency.

## 🛠 **Local Development**

```bash
pnpm install
pnpm dev
```

Static production build (deployed on Netlify from `out/`):

```bash
pnpm build
pnpm start
```
